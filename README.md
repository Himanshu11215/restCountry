<h1 align="center">🌍 Country Info Finder 🌍</h1>

<p align="center">
  A sleek web app that fetches and displays detailed information about any country using the <a href="https://restcountries.com/">REST Countries API</a>.
</p>

<br>

## ✨ Features

- 🔎 Search for any country by name  
- 🏳️ Displays country **flag**, **name**, **capital**, **currency**, **population**, **area**, and more  
- 💡 Instant results with a clean layout  

<br>

## 🛠 Tech Stack

- ⚙️ HTML  
- 🎨 CSS  
- 🧠 JavaScript  
- 🌐 [REST Countries API](https://restcountries.com/)  

<br>

## 🚀 How to Use

1. Open the app in your browser  
2. Type a country name in the search field  
3. Hit **Enter** or click **Search**  
4. View all the country details instantly
